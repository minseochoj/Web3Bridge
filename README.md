Serves as a bridge between Web2 and Web3 networks, enabling developers to interact with decentralized apps seamlessly.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/Web3Bridge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure Web3Bridge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
